# Program 4: Website Promosi & Pemasaran (React + TypeScript)

Halaman landing page publik berkecepatan tinggi dengan skor Core Web Vitals optimal, dilengkapi **Interactive Live Sandbox Demo**, kalkulator paket, dan showcase arsitektur.

## 🚀 Cara Menjalankan Lokal

```bash
# 1. Masuk ke direktori
cd services/04-marketing-site

# 2. Pasang dependensi
npm install

# 3. Jalankan server pengembangan
npm run dev
```

Buka browser di: [http://localhost:3000](http://localhost:3000)

## 📦 Build Produksi
```bash
npm run build
```
Hasil build akan tersimpan di direktori `dist/`.
