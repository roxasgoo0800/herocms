# Program 2: Dashboard CMS Studio (Vue 3 + Vite + Pinia)

Panel studio visual untuk pelanggan dalam mengedit website portofolio/blog, menerbitkan konten ke kontainer Docker, dan memanfaatkan asisten AI.

## 🚀 Cara Menjalankan Lokal

```bash
cd services/02-dashboard-cms
npm install
npm run dev
```

Buka browser di: [http://localhost:5173](http://localhost:5173)
